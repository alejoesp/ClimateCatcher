Datos meteorológicos del lugar, disponibles desde la web

ClimaInn recibe las mediciones de temperatura, humedad, presión atmosférica y luminosidad enviadas por ClimateCatcher para guardarlas y consultarlas desde el panel.

Acerca del proyecto

ClimateCatcher nació como un proyecto para conectar una estación meteorológica física con una aplicación web. La estación registra datos del ambiente en un punto concreto y los envía al servidor para que puedan consultarse después desde una computadora o un celular.

Las mediciones se guardan en la base de datos y el panel permite revisar valores actuales, historial, promedios y gráficos. De esta forma se puede seguir todo el recorrido del dato, desde el sensor hasta su visualización en la web.

El objetivo del prototipo es contar con información tomada directamente en el lugar donde está instalada la estación, en lugar de depender únicamente de mediciones generales correspondientes a otros puntos de una ciudad o región.

El problema que buscamos resolver

La temperatura, la humedad, la presión y la luminosidad pueden variar entre distintos puntos de una misma zona. Muchas fuentes meteorológicas muestran datos tomados a varios kilómetros o valores generales para una ciudad completa. El proyecto parte de esa diferencia y propone registrar las condiciones directamente en el lugar donde se instala la estación.

¿Cuáles son los factores que inciden en la dificultad de obtener datos climáticos?

1) La ubicación de la estación de referencia puede estar lejos del lugar que se quiere observar.

2) Los datos necesitan actualizarse con frecuencia para representar cambios del ambiente.

3) La información tiene que presentarse de una forma clara para poder comparar valores e historial.

Nuestra solución

ClimateCatcher mide las condiciones del lugar, envía los valores al servidor y los almacena para poder consultarlos más tarde. La aplicación web permite ver esas mediciones, revisar registros anteriores y representar los datos en gráficos.

Registrá tu dispositivo

Si ya tenés una estación asociada al proyecto, podés registrarla para vincularla con tu cuenta y empezar a consultar sus mediciones.

¿Cómo iniciar sesión?

Si ya registraste tu dispositivo, ingresá con tus datos desde la opción "Iniciar Sesión".
